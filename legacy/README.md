# Legacy scripts

The original single-file scripts, kept for reference. Everything they did is now in the apps:

| Old script | Replaced by |
|---|---|
| `okr_gui_experiment.py` (PsychoPy) | OKR Drum app, **Stimulus** and **Rig** tabs |
| `okr_record_pi.py` (run in Thonny) | **OKR Drum recorder** on the Raspberry Pi (`OKR-Drum-x-RaspberryPi.deb`) |
| `okr_camera_calibration.py` | OKR Drum app, **Tools → Camera calibration** |

They still work, but are not maintained. The PsychoPy script needs PsychoPy; the recorder needs picamera2.
